# Ritm

Личный планер в чёрно-белом стиле: пары, самоподготовка, зал и дорога в одном недельном графике.

- **Сегодня**: план дня, время выезда на завтра, ближайшие задачи.
- **Неделя**: шаблон недели. Дорога до университета считается сама, в час пик с запасом.
- **Учёба**: предметы, текущие проценты, GPA по шкале A–F, задачи с дедлайнами.
- **Зал**: сплит, программы с подходами и весами, отметки посещений.

Работает как веб-приложение (PWA): на iPhone через Safari → «Поделиться» → «На экран Домой», на Mac через Safari → «Файл» → «Добавить в Dock». Работает без интернета.

## Данные

В этом репозитории нет личных данных. Всё хранится на устройстве и, если в настройках указан токен, синхронизируется в `data.json` отдельного **приватного** репозитория через GitHub API. Токен хранится только в браузере устройства.

Токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → доступ только к приватному репозиторию с данными, Contents: Read and write.

## Обновление

После изменения файлов увеличь `VERSION` в `sw.js`, чтобы устройства подхватили новую версию.
